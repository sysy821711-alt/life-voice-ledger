# iPhone「捷徑」快速記帳設定

完成後可以說「嘿 Siri，記帳」，口述「午餐 180 元」。記帳貓會開啟既有確認表單並預填收支類型、金額、類別與備註；資料要等你檢查後按「儲存」才會寫入。

## 使用前準備

1. 先用 iPhone 開啟 <https://sysy821711-alt.github.io/life-voice-ledger/>。
2. 確認記帳貓裡已經建立至少一個帳本。
3. 建議先把網頁「加入主畫面」，並從主畫面打開一次，確認原本的帳本與紀錄都看得到。

## 建立捷徑

1. 打開 iPhone 的「捷徑」App，點右上角「＋」，將名稱改成「記帳」。
2. 加入「聽寫文字」動作：
   - 語言選「中文（台灣）」。
   - 停止聆聽可選「暫停後」。
3. 加入「URL 編碼」動作：
   - 輸入選上一個動作的「聽寫文字」。
   - 模式選「編碼」。
4. 加入「文字」動作，填入以下內容，並把最後一段換成上一步的「URL 編碼」變數：

   ```text
   https://sysy821711-alt.github.io/life-voice-ledger/?shortcut=1&text=[URL 編碼]
   ```

   `[URL 編碼]` 是捷徑中的變數泡泡，不是手動輸入的普通文字。

5. 加入「URL」動作，輸入選上一步的「文字」。
6. 加入「打開 URL」動作，輸入選上一步的「URL」。
7. 點「完成」。捷徑名稱是「記帳」時，就能說「嘿 Siri，記帳」執行。

動作順序應該是：

```text
聽寫文字 → URL 編碼 → 組合網址文字 → URL → 打開 URL
```

## 測試

第一次先在「捷徑」App 裡按下執行按鈕，說「午餐 180 元」。預期結果：

- 記帳貓打開「確認捷徑記帳」表單。
- 類型是「支出」、金額是 `180`、類別是「餐飲」、備註是「午餐」。
- 尚未產生任何紀錄；必須按「儲存」才會寫入目前裝置的帳本。
- 按「取消」不會新增紀錄。

## 常見狀況

- 若出現「目前沒有帳本」，先在記帳貓建立帳本，再重新執行捷徑。
- 若網址中的中文變成亂碼，檢查「URL 編碼」動作是否放在組合網址之前。
- 若 Siri 找不到捷徑，確認捷徑名稱就是「記帳」，或在 Siri 設定中允許使用「捷徑」。
- 捷徑只是把文字帶入確認表單；帳本、統計、預算、定期收支與備份格式都沒有改變。

如果要從「訊息」、LINE 或「照片」分享收據圖片，請改用[「記帳貓收據」分享捷徑](iphone-receipt-shortcut.md)。
