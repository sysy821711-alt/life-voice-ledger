# iPhone「記帳貓收據」分享捷徑

這個捷徑可從「訊息」、LINE、WhatsApp、「郵件」或「照片」分享一張收據圖片。iPhone 先在捷徑中辨識圖片文字，再打開記帳貓的確認表單；資料不會直接入帳。

## 使用前準備

1. 先用 iPhone 開啟 <https://sysy821711-alt.github.io/life-voice-ledger/>。
2. 確認記帳貓已建立至少一個帳本，而且能看到原本的紀錄。
3. 建議將記帳貓「加入主畫面」，並從主畫面打開一次。

## 建立「記帳貓收據」捷徑

1. 打開 iPhone 的「捷徑」App，點右上角「＋」。
2. 將捷徑名稱改成「記帳貓收據」。
3. 打開捷徑的詳細資訊：
   - 開啟「在分享表單中顯示」。
   - 輸入類型只保留「影像」。
   - 若沒有收到輸入，設定為「停止並回應」，訊息可填「請先分享一張收據圖片」。
4. 加入「從影像擷取文字」動作，輸入選「捷徑輸入」。不同 iOS 版本可能顯示為「從影像擷取文字」或「擷取影像中的文字」。
5. 加入「URL 編碼」動作：
   - 輸入選上一步辨識出的文字。
   - 模式選「編碼」。
6. 加入「文字」動作，輸入以下網址，並把最後的 `[URL 編碼]` 換成上一步的變數泡泡：

   ```text
   https://sysy821711-alt.github.io/life-voice-ledger/#shortcut=receipt&text=[URL 編碼]
   ```

7. 加入「URL」動作，輸入選上一步的「文字」。
8. 加入「打開 URL」動作，輸入選上一步的「URL」。
9. 點「完成」。

完成後的動作順序應為：

```text
分享的收據圖片
→ 從影像擷取文字
→ URL 編碼
→ 組合記帳貓網址
→ URL
→ 打開 URL
```

## 從訊息中使用

1. 在「訊息」、LINE 或其他 App 中打開收到的收據圖片。
2. 點「分享」。若 App 沒有直接顯示分享按鈕，可先把圖片儲存到「照片」。
3. 在分享表單中選「記帳貓收據」。第一次找不到時，點「更多」並把它加入常用項目。
4. 記帳貓會打開「確認收據記帳」表單。
5. 檢查金額、類別、日期、店家備註與付款方式，確認無誤後按「儲存」。

## 記帳貓會怎麼判讀

- 金額：優先找「實付金額、應付金額、交易金額、支付金額、總計、合計、總額」。
- 店家：從收據前面的文字中找第一個像店名的內容，填入備註。
- 日期：支援西元日期、民國年，以及收據上的時間。
- 類別：沿用原本的關鍵字與自訂類別；全聯、家樂福、好市多、便利商店等會預設為購物。
- 付款方式：辨識現金、信用卡、金融卡、Apple Pay、Line Pay、悠遊卡、銀行轉帳，以及名稱出現在收據上的自訂付款方式。

若找不到可信的總金額，金額欄會保持空白並提醒手動填寫，不會拿發票號碼或日期冒充金額。

## 注意事項

- 一次分享一張收據，並盡量裁掉聊天背景或其他無關畫面，辨識會更準。
- 收據文字會暫時放在 `#` 後面的網址片段中；這一段不會傳送到 GitHub Pages 主機，記帳貓讀取後也會立即清除。
- OCR 原文只會在你按「儲存」後，跟著該筆交易存在目前裝置的記帳貓資料中。
- 收據圖片本身不會寫入記帳貓，也不會改變現有備份格式。
- 這個流程不會在背景讀取所有訊息；只有你主動分享的圖片會被處理。
